语音输入与输出

选择供应商实际提供的音频接口。对话模型、语音识别和语音合成可以使用不同服务。

macOS 使用 ⌘+Shift+Space。按一次开始，再按一次结束并发送；最长录音60秒。开始说话会打断旧回复。快捷键只对本应用生效，不控制游戏。

长期记忆

跨对话保留的事实和偏好；可以查看、纠正或遗忘。

从之后的对话整理偏好和事件，会调用已配置模型。默认关闭，明确保存随时可用。

记忆快照

本机保存人格和长期记忆。恢复旧快照会保留之后的纠正和遗忘，不会恢复已遗忘的内容。
