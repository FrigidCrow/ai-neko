## 后端测量与真实验收记录

[measure_guides.py](../scripts/measure_guides.py)记录20组同题冷暖对照：冷路必须成功搜索并读取计划来源，随后采用该保存版本；暖路在独立会话询问同题，避免复用冷回答历史。记录模型调用、工具结果、本地检索耗时、后端文本投递时刻、供应商报告usage和费用依据。失败样本保留，不自动重试或从20组中删去；缺失usage、价格、首个有效文字或语音时刻保持unknown/null。

当前合成20对只证明这个后端记录流程。`first_text_ms`是后端事件投递时刻，不是UI首个有效建议，也不是扬声器实际发声；“我先核对资料”等占位文字不得作为有效建议。脚本报告明确ASR/TTS为`NOT_RUN`。本轮没有真实服务冷暖性能结论，G3的200篇检索p95也不能替代端到端测量。

流式usage处理参考[OpenAI官方流式示例](https://developers.openai.com/cookbook/examples/how_to_stream_completions)与[DeepSeek Chat Completions接口](https://api-docs.deepseek.com/api/create-chat-completion/)。本工程仅保留供应商报告的有界数值；累计usage按请求最新总量计一次，空choices不丢掉末尾usage，中断或不完整计量不假称完整。`request_usage`默认关闭；测量显式启用时才发送`stream_options.include_usage=true`，供应商不支持该字段时不会自动发起第二次可能计费的请求。

独立的[人工记录工具](../scripts/record_guides_acceptance.py)及[使用手册](MVP2-LIVE-ACCEPTANCE.md)已经实现：固定20对、10游戏轮、3公开来源和20停止样本；按实际投递的Unicode结束位置人工标记有效文字，实际ASR请求/转写、TTS请求/监听和同钟证据须另填。导入时保留原probe与摘要、机器字段和失败结果；检索必须属于对应turn，不允许通过修改外层状态抹掉失败。10项回归及实际CLI证明空模板和合成导入均为PENDING，返回码2，40份分阶段检索指标保留。审核PASS只代表所填记录满足一致性规则，工具不认证外部证据或自动听到声音。

停止时延的20个样本要求旧句确实仍在硬件播放，同时分别覆盖后续生成、下一句合成及仅播放；尚未发声的取消不能填0ms凑数。开口至收到取消与收到取消至实际旧声停止分开，p95按nearest-rank计算。记录不对真实服务或Windows结果自动填PASS。

## 发现与修复

- 冷暖探针发现中文与数字混合标识在查询/正文分词中形态不同，使确有依据的名称出现缺口。检索补充单一混合主体的精确原文匹配，并保留数字边界：`灯芯10`不能由`灯芯100`、`灯芯110`、`灯芯10a`支持，前导零也不擅自归一。修复后83项专项通过，冻结30题再次达标；未修改冻结题目或标签。
- 测量脚本原先在Runtime构造或关闭失败时会中断剩余计划，遗漏样本。现将每组构造、测量和关闭纳入独立结算，逐组保存失败阶段与安全错误类型，继续保留后续组；异常文本和凭据不进入报告。
- 冷路搜索失败后直接读取成功曾仍被视为合格冷路。现必须同时有成功搜索和成功正文读取，失败搜索组保留为不合格，不能用于冷暖对照结论。修复前3失败/3通过见`g6-measurement-before-fixes-20260930.log`，修复后13项通过。
- 旧版升级测试的故障注入最初在任意首个来源删除后抛错，来源遍历顺序可能使目标事实尚未提交。现仅在目标真实来源提交后注入，保留“提交后事实已删除”的断言；该项是测试修复，没有修改产品。失败日志`g6-v04-final.txt/xml`保留，最终6项通过。
- 数字名称门禁随后收窄为中文前缀加数字/ASCII后缀，普通含数量问句继续使用原覆盖逻辑；新增实际检索断言证明“蓝色水晶达到8枚能部署银鹰吗？”不会被要求整句字面相等，专项84项通过。
- 首次全量中，旧测试把随机observation ID里的`937`误判成旧局金币泄漏。改为检查完整旧描述、空观察及新帧实际fields，不删除隔离断言；相同测试文件的其他裸数字断言一并改为完整描述。失败输出保存在`g6-first-failed-pytest-final.txt/xml`，仅此测试文件改变，生产/桌面/构建源码保持一致。实际Electron结果对应的产品与最终产品相同，全量Python重新冻结执行。
- 人工记录器审查补足声音不得早于首字、导入失败与机器字段不可外层改写、检索turn归属、bool/畸形类型和巨整数处理。测试以文件路径导入CLI脚本，修复仅`python -m pytest`可收集而普通`uv run pytest`缺少scripts路径的问题；两种入口均可执行。
