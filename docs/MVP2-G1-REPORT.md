日期：2026-09-27。基线为MVP1收尾后的`e830730`工作区，本批次尚未提交/推送/发布。**G1实现与本机合成验收通过**，最终回归结果见文末；MVP2完整目标仍在进行，G2–G6继续按[NEXT-GUIDE-COMPANION](NEXT-GUIDE-COMPANION.md)执行。

## 实现结果

- Memory Service拥有独立`guides/guides.sqlite`。文档、不可变正文版本、核查记录和可重建段落分开存储，保留来源、日期、游戏版本依据和完整性。scope由服务固定，网页不变成用户事实或人格。
- 公开网页正文最多保留50,000字符，在LangGraph裁剪至6,000字符、回答节点再裁剪至4,000字符之前保存。列表、表格与标题位置保留；图片/嵌入内容未读、解码替换、保留超限均标记部分内容。登录、403、空页和snippet不能进入正文库。
- 同原URL、同正文去重，不丢查询参数；不同来源分别保留。后续抓取新增图片或超限内容，即使保存前缀相同，也会在核查记录中保留新的缺失信息，不能继续声称完整。不可变版本的初始元数据不被覆盖。
- 100MiB逻辑载荷限额含正文、元数据与段落副本；SQLite页/日志另计。LRU仅清理当前scope未保护的自动缓存，无法回收则整次写入回滚。保护标志是G2采用关系的内部基础，不是已实现采用功能。
- 来源事件含稳定文档/版本ID、保存结果、完整性和截断标记。桌宠和Web页面显示已读取、已保存部分内容或保存失败；这里只增加状态说明，攻略库管理入口尚待G5。
- 取消后迟到抓取不入库；已经开始的缓存写入会结算，但不继续发来源/调用模型。补修工作线程在取消后报错会覆盖取消信号的问题，覆盖成功与失败两种关闭路径。

精确内部接口见[ARCHITECTURE](ARCHITECTURE.md)。本批次没有新增第三方依赖或导入参考项目源码/素材。
