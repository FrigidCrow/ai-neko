# 免费本地语音

2026-10-03：按用户选择，ai-neko 新增无需账号或 API Key 的本地中文语音。SenseVoice Small INT8 负责录音转文字，Kokoro v1.1 中文 INT8 负责朗读，使用 CPU。下载完成后，语音推理不访问云端，不产生语音 API 费用；聊天大模型仍在模型设置中单独配置。

## 使用

1. 打开猫娘旁的设置，在语音部分选择“本地免费语音”。
2. 保存选择，点击下载并启用。两个模型约 310 MB，另需下载专用运行组件，建议预留 2 GiB；首次安装需要联网，下载可取消和重试。
3. 显示已就绪后，点击试听。试听不依赖聊天模型。
4. 选择麦克风，点击“说话”开始录音，再次点击结束；勾选朗读回复。回答仍由已配置的聊天模型生成。

安装按用户明确点击执行，不在打开设置或启动应用时自动下载。切换模式保留原有云服务地址和 Key，本地模式不会在失败时回退到付费服务。录音上限 60 秒；前端转换为单声道 16 kHz、16 bit PCM WAV。语音在内存和子进程管道中处理，不落盘为用户录音文件。

运行组件和模型仅安装到本项目数据根的 `assets/voice` 下。Windows 默认为 `%LOCALAPPDATA%\ai-neko\assets\voice`，也遵循显式独立数据根；不使用系统 Python、旧 N.E.K.O 环境或其他项目的模型、数据和凭据。主应用仍可直接启动，免费语音组件首次安装后才能使用。

## 实测与边界

Mac M4 上已下载固定版本组件并执行真实中文 TTS 与 ASR。[实际应用接口报告](evidence/mvp2/free-voice/source-api-smoke.json)记录24字测试句的朗读、回识别、官方样例、实际进程取消及正常退出；[短句引擎报告](evidence/mvp2/free-voice/engine-probe.json)保留另一短句的一字识别偏差。输入使用固定文本、模型合成音频及官方样例，没有采集用户麦克风。单段成功不能证明任意中文、游戏术语或噪声下的准确率。

[中文女声测试音频](evidence/mvp2/free-voice/source-api-smoke-final-speech.wav)可单独试听；音频为本地模型真实合成，尚未做主观音色或硬件播放验收。

每次请求独立启动推理进程，因此第一次和后续请求都包含模型加载时间。取消、切换语音模式和退出应用会取消相关任务，并等待推理进程结束；停止音频仍由已有播放器即时清空播放。模型推理取消、播放器停止和硬件真正静音是不同的测量，后者仍需真实设备验收。

Windows Server CI 将从同一个应用 ZIP 解压后的后端触发安装，实测中文合成和回识别，报告为 `free-voice-smoke.json`。它与既有合成服务的陪伴测试分开计数；Mac 测试和 Windows Server 测试均不能代替 Windows 11 游戏、麦克风与音色试听。CI 完成前不将其记为通过。

## 来源与升级

[版本、下载校验与许可证](FREE-VOICE-SOURCES.md)记录组件来源。语音原生库作为独立可选运行组件由原发布者下载安装，不打进主应用冻结解释器；依赖锁、安装器和 worker 源码随应用提供。升级需同时更新固定下载摘要、专用依赖锁、来源记录及真实模型/Windows 包测试，不能只改模型名称。
