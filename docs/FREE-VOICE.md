# 免费本地语音

当前发布准备状态（2026-10-10）：语音接入和真实声音验收已暂停。本轮仅对现有语音代码执行合成回归、取消与资源清理审查，不下载模型，也不把下方历史实测计入本候选。Qwen 专用实验环境与模型已可恢复地回收；登记清单不能证明资源仍可用。重新使用前须另行恢复并核验，当前不能承诺 Qwen 可运行、1–2 秒首声或硬件音色通过。普通文字、搜索和 Windows 窗口观察的验收另行记录。

2026-10-04：按用户选择，ai-neko 新增无需账号或 API Key 的本地中文语音。SenseVoice Small INT8 负责录音转文字，Kokoro v1.1 中文 INT8 负责朗读，使用 CPU。下载完成后，语音推理不访问云端，不产生语音 API 费用；聊天大模型仍在模型设置中单独配置。

## 使用

1. 打开猫娘旁的设置，在“语音输入与输出”中选择“免费本地语音（无需 Key）”。
2. 点击“下载并启用免费语音”，按钮会保存选择并开始准备。两个模型约 310 MB，另需下载专用运行组件，建议预留 2 GiB；首次安装需要联网，下载可取消和重试。
3. 显示已准备好后，可设置“本地声线编号”（0–102，默认 46）。中文女声为 3–57；默认 46 对应 `zf_079`。保存后点击“试听已保存的音色”；试听不依赖聊天模型。编号只控制本地 Kokoro，和云服务的音色名称分开；女声标签不保证某种年龄或听感。
4. 选择麦克风，点击“说话”开始录音，再次点击结束；勾选朗读回复。回答仍由已配置的聊天模型生成。

安装按用户明确点击执行，不在打开设置或启动应用时自动下载。切换模式保留原有云服务地址和 Key，本地模式不会在失败时回退到付费服务。录音上限 60 秒；前端转换为单声道 16 kHz、16 bit PCM WAV。语音在内存和子进程管道中处理，不落盘为用户录音文件。

运行组件和模型仅安装到本项目数据根的 `assets/voice` 下。Windows 默认为 `%LOCALAPPDATA%\ai-neko\assets\voice`，也遵循显式独立数据根；不使用系统 Python、旧 N.E.K.O 环境或其他项目的模型、数据和凭据。主应用仍可直接启动，免费语音组件首次安装后才能使用。

## 实测与边界

Mac M4 上已下载固定版本组件并执行真实中文 TTS 与 ASR。[最新实际应用接口报告](evidence/mvp2/free-voice/source-api-smoke-pipe-fix.json)记录最终管道修复后的9项实测：24字测试句的朗读约6.636秒、回识别约0.696秒且CER为0，另含官方样例、实际进程取消及正常退出；[短句引擎报告](evidence/mvp2/free-voice/engine-probe.json)保留另一短句的一字识别偏差。输入使用固定文本、模型合成音频及官方样例，没有采集用户麦克风。单段成功不能证明任意中文、游戏术语或噪声下的准确率。

[中文女声测试音频](evidence/mvp2/free-voice/source-api-smoke-pipe-fix-speech.wav)可单独试听；音频为本地模型真实合成，尚未做主观音色或硬件播放验收。

当前工作树复用一个受控本地推理进程，ASR/TTS 各自在首次使用时加载模型，后续请求复用；推理仍串行执行。取消活动推理、超时、协议异常或退出应用时终止并等待进程回收，下次请求重新加载，不自动重放失败请求。朗读最多预取下一段，减少句间等待；首段仍包含首次加载和整段合成时间。停止音频由已有播放器即时清空播放。模型推理取消、播放器停止和硬件真正静音是不同的测量，后者仍需真实设备验收。此优化尚未包含在下方历史开发包中。

[Windows 开发包](https://github.com/FrigidCrow/ai-neko/actions/runs/37135192000/artifacts/11278787928)（`0.4.0-dev.b443768df012`）已通过真实免费语音11项检查及[实际下载核对](evidence/mvp2/free-voice/windows/windows-download-verification.json)。从同一 ZIP 解压后的程序在中文和空格目录中完成安装，约37.5秒；固定短句合成约17.297秒，音频约6.6095秒，识别约2.219秒。归一化文字CER为0，但原始识别多了一个逗号，不能称逐字完全一致。两个独立后端进程验证重启后资源就绪、无需重新下载，见[真实包语音报告](evidence/mvp2/free-voice/windows/free-voice-smoke.json)。

[Windows 实际合成音频](evidence/mvp2/free-voice/windows/free-voice-smoke-speech.wav)可试听。上述耗时来自CI机器和单个固定样本，初版每请求加载模型，尚不适合承诺即时语音。免费语音与聊天模型的费用/响应分别计算，聊天模型仍需单独配置。真实免费语音报告与使用合成服务的桌面闭环分开计数；Mac和Windows Server均不替代Windows11游戏、用户麦克风、噪声/术语准确率与硬件音色试听。

## 已验收音色的 Qwen 本机接入（2026-10-06 工作树）

设置中的本地朗读引擎可选“Qwen 清甜俏皮（NVIDIA GPU）”，保留 CPU/Kokoro 和云语音选项；识别仍使用 SenseVoice。Qwen 使用本次已安装的 Base0.6B、独立 Python 环境和已验收的原创参考音色缓存，不需要语音 API Key。这个适配器目前只登记本机已批准的固定安装，不是通用的自动安装器；新机器尚未验证。原有开发包也不会因工作树修改自动更新。

本机登记命令为 `.venv/Scripts/python.exe -B scripts/register_qwen_runtime.py --data-dir <本应用数据根> --idle-unload-seconds 300`。它校验既有资源并写入本应用 `assets/qwen` 的小清单，不复制模型、不修改原音色、不联网。界面不接受任意 Python 或模型路径。登记完成后选择 Qwen 并保存；可预热或释放模型。启用朗读时的按需预热用于将加载与文字生成重叠，空闲5分钟后释放，关闭应用也回收子进程。预热期间会占用内存及显存，状态和错误会显示在设置中；失败不会自动改用云端收费服务。

已有四段完整音频的音色已由用户认可。此前实测生成4.8–6.4秒音频需8.61–10.91秒；这些是独立实验的整段耗时，不能当作实际聊天首声延迟。当前按自然短句合成，并最多预取下一段；此接口不是逐块音频流。冷启动、暖态首声和连续多句的真实应用验收仍在进行，目标1–2秒尚未证明。播放器开始事件也不能替代硬件声音验收。当前资源保护为加载前可用RAM至少1.5GiB、commit至少8GiB、空闲GPU至少3GiB；这是本轮保守保护线，不是上游公布的最低硬件需求。
