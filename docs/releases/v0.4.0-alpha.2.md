## 本次候选范围

- 文字对话和流式显示、设置草稿与保存状态、外观持久化失败反馈，以及取消、迟到响应和恢复行为的可靠性修复。
- 本地长期记忆设置、编辑/删除及异步任务状态处理；SQLite 升级、备份与恢复继续纳入回归。合成恢复或隔离数据库副本通过，不等于完成真实应用升级验收。
- 自动记忆纠正引用已有事实的身份、修订号和用户原话证据，沿用事实及来源历史，不再靠模型独立生成的语义键直接创建纠正记录。无法验证或有歧义的纠正会被拒绝；后台状态单独显示，抽取完成不代表每句话都已保存。本次不新增数据库迁移，也不自动合并或删除历史记录。
- 网页导入准确区分读取失败、超时、压缩响应、取消和修订冲突；结果尚未确认时重试核对原操作。公开地址、响应大小和压缩响应拒绝策略保持不变。
- 新增持久的模型请求与供应商使用量记录，区分对话生成和记忆提取。缺失、部分、取消、中断和旧历史的使用量保留明确未知状态；本地发起记录不等于供应商已接收或已计费。
- 观察画面仅支持用户明确选择的 **Windows 窗口**。窗口列表枚举不生成图片；实际捕获绑定选中窗口，撤销、窗口失效或过期时停止，不回退到整屏或其他窗口。整屏观察不可用；部分游戏、最小化或受保护窗口可能无法提供有效画面。预览成功与游戏内容识别质量需要各自验证。
- Windows 原生窗口捕获助手随包重新编译，并记录源码、可执行文件及编译器摘要。用户无需自行编译，实际包的 Windows 11 生命周期和兼容性仍以本候选验收为准。

既有桌宠、人格、攻略库、对局管理、带来源搜索与网页读取继续参与回归。不新增键鼠接管、多角色导入或免按键语音唤醒。

## 语音范围

**语音接入与真实语音验收继续暂停。** 保留既有语音代码和合成测试；本轮不新增供应商接入、不安装专用语音运行环境或下载模型、不进行真实语音推理。实验性 Qwen 适配代码不等于已验收、可直接使用的语音功能，私人模型、运行环境和样本不随源码或应用包分发。

默认 CI 的 `Windows-voice-import-smoke.json` 和 `free-voice-smoke.json` 明确记录 `SKIPPED_PAUSED`、未执行、零语音组件/模型下载和零真实语音调用。历史版本的真实语音成功不能替代本候选验收。后续真实语音检查需要手动显式选择 `run_real_voice=true`，本轮不触发。

## 安装与数据边界

发布后的预期附件为 `ai-neko-0.4.0-alpha.2-windows-x64.zip`、`build-info.json`、`SHA256SUMS.txt` 和对应验收报告；目前没有本候选下载链接。完整解压到独立程序目录后启动 `ai-neko.exe`，首次阅读并选择是否接受 Live2D 条款。猫娘素材、运行依赖和第三方许可随包保留；应用尚未签名。

升级前退出旧程序并备份数据，新程序解压到新目录；数据根默认是 `%LOCALAPPDATA%\ai-neko`，或用户明确设置的独立 `AI_NEKO_DATA_DIR`。SQLite 按版本升级，回退旧程序前应使用对应版本备份，不把新旧进程同时连到同一数据根。应用不读取原 N.E.K.O. 的配置、数据或凭据。

私密聊天、截图、凭据、数据库、缓存、虚拟环境和模型不属于提交或发布制品。配置自己的聊天模型后，服务调用可能产生费用；缺失的供应商使用量不会被推断为零费用。
